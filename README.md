## Overview

YourControls Profile Manager handles the configuration profiles for YourControls, the Microsoft Flight Simulator multiplayer co-pilot sync addon, allowing pilots to save, share, and organize aircraft-specific variable sync configurations — making it easy to share control assignments with co-pilots before a shared flight.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **YourControls Profile Manager** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Profile Library** | Organize aircraft-specific YourControls sync profiles by aircraft |
| **Community Import** | Import community-shared profiles for any MSFS aircraft |
| **Variable Viewer** | Browse synchronized variables in each profile before loading |
| **Quick Share** | Export profiles as single files for direct sharing with co-pilots |
